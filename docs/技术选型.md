# 人工智能实验室在线问答系统 — 技术选型

> 状态：✅ 已确认（2026-08-03）
> 项目目录：`D:\FullStack\ragent-SpringAI`
> 背景：人工智能实验室场景，学生围绕 AI 实验课提问，教师/助教解答，AI 基于实验室知识库做 RAG 智能问答（带引用溯源）。

---

## 一、已确定的三大核心决策

| 维度 | 决策 | 备注 |
|---|---|---|
| LLM 服务商 | **DeepSeek**（deepseek-chat） | 国内直连，价格低，中文强。**无 embedding 接口** → 向量化单独解决 |
| 存储方案 | **MySQL（业务）+ Qdrant（向量）** | MySQL 存用户/问答/知识库元数据；Qdrant 存文本切片向量。（原选 Milvus，镜像国内源拉不到，2026-08-03 已切换） |
| 前端 UI | **Tailwind CSS 自研组件库** | 无现成 UI 库，P0 必须先建设计系统 + 基础组件 |

## 三、后端技术栈

| 层面 | 选型 | 说明 |
|---|---|---|
| 语言/运行时 | **JDK 21 (LTS)** | 需本机安装 |

| 流式输出 | **Spring MVC + Flux(SSE)** | 官方 SSE 协议流式吐字 |
| 构建 | Maven（已装 3.9.12） | 多模块：`-common / -ai / -web` |

## 六、数据模型概览

**MySQL 表：** user、question、answer、tag、question_tag、comment、vote、feedback（AI 回答赞踩）、conversation（对话）、document（知识库文件元数据）、document_chunk（切片元数据 + Qdrant point id）

**Qdrant Collection：** `doc_chunk` — 字段：`id`、`document_id`、`chunk_text`、`vector`

> 关联方式：切片实体存 MySQL（含 Qdrant 的 point id），向量本体存 Qdrant。删除文档时两处同步清理。

## 七、重点要做的方向（按优先级）

**核心主线（决定项目成败）**
1. **RAG 实验室知识库** — 文档上传 → 切分 → 向量化 → 检索 → 带引用生成
2. **高质量检索** ✅ — 混合检索（MySQL FULLTEXT ngram 关键词 + Qdrant 向量，RRF 融合）+ 重排序（百炼 gte-rerank-v2），答案可溯源到原文段落
3. **师生问答闭环 + AI 协同** — 提问/回答/采纳最佳答案 + AI 多轮对话（SSE 流式）
4. **Agent 工具调用** — Spring AI tool calling：AI 查题库、查设备预约、统计提问

**技术亮点（加分项）**
5. 多轮会话记忆管理（Redis 上下文）
6. 数学公式渲染（KaTeX）
7. AI 答案反馈闭环（赞/踩反哺知识库）
8. 数据统计看板（ECharts）
