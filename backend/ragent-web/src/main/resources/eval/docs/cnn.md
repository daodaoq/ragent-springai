# 卷积神经网络基础

## 卷积层
卷积层通过滑动窗口（卷积核/滤波器）对输入做卷积运算，提取局部特征。卷积核在同一层内共享权重，因此大大减少了参数量。不同的卷积核能够提取边缘、纹理、颜色等不同层次的特征。

## 池化层
池化层用于降采样，常见最大池化和平均池化两种。池化能增强特征的平移不变性并减小后续计算量。

## 全连接层
特征经过若干卷积和池化后，由全连接层把高层特征映射到最终的分类结果。

## 经典结构
LeNet、AlexNet、VGG、ResNet 等。其中 ResNet 通过残差连接（shortcut）缓解深层网络的梯度消失与退化问题，使得上百层的网络也能稳定训练。

## 实际应用
卷积神经网络广泛应用于图像分类、目标检测（如 YOLO 系列）、语义分割、人脸识别等计算机视觉任务。
