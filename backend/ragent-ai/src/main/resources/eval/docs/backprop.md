# 反向传播算法

## 核心思想
反向传播通过链式法则，从输出层向输入层逐层计算损失函数对每个权重的梯度。它解决了多层神经网络中权重参数如何高效更新的问题，是深度学习的基石算法。

## 计算过程
前向传播先计算出预测值，再与真实标签对比得到损失；反向传播从损失出发，利用链式法则把梯度逐层向前回传；最后用梯度下降法更新各层权重。

## 数学表达
对第 l 层的权重 W，其梯度等于损失对输出的偏导乘以输出对权重的偏导。误差项 delta 逐层传递：
delta^l = (W^{l+1})^T delta^{l+1} 点乘 f'(z^l)
其中 f' 是激活函数的导数，z^l 是该层神经元输入。

## 实际意义
反向传播让深层网络的训练变得可行，几乎所有深度学习框架（PyTorch、TensorFlow）都在框架层面自动实现了该算法，开发者无需手工求导。
